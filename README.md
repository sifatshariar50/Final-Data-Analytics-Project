# Final-Data-Analytics-Project
📊 Amazon Sales Analysis Dashboard

📌 Project Overview

This project focuses on analyzing Amazon e-commerce sales data to identify sales trends, product performance, customer behavior, and business insights through data analytics and visualization.

🎯 Project Objectives

Analyze overall sales and revenue.

Identify top-performing products.

Understand monthly sales trends.

Analyze country-wise revenue.

Explore customer purchasing behavior.

Generate meaningful business insights.

🛠️ Tools & Technologies

Python

Pandas

NumPy

Matplotlib

Seaborn

Jupyter Notebook

Power BI

📈 Key Performance Indicators (KPIs)

Total Orders

Average Order Value

Total Quantity

Total Customers

Total Revenue

📊 Dashboard Preview

The dashboard provides a visual representation of:

Monthly Revenue Analysis

Revenue by Product Description

Revenue by Country

Customer-wise Revenue Analysis

Product Quantity Analysis
